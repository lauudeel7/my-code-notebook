## 🎯 Enunciado

Declara `var dato = "55"` y `var numero = 55`. Muestra por consola los resultados de compararlos con `==` y `===`, junto con el `typeof` de cada variable. Comprueba también qué ocurre al comparar una variable no inicializada con `null` y con `undefined`, usando ambos operadores.

## 🧠 Conceptos que aparecen

- `==` frente a `===`
- `typeof`
- `null` y `undefined`

## 🧪 Casos que debo probar

- [ ] Comparar string y number
- [ ] Comparar variable no inicializada
- [ ] Explicar cada resultado

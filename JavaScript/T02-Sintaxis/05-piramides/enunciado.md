# 05 · Pirámides de números

![Practice](https://img.shields.io/badge/JAVASCRIPT-PRACTICE-F6A8C8?style=flat-square)

</div>

## 🎯 Enunciado

Crea dos patrones: (1) una pirámide del 1 al 30 repitiendo cada número tantas veces como su valor (`1`, `22`, `333`, ...); (2) pide un número no mayor de 50 y genera una pirámide secuencial (`1`, `12`, `123`, ...). Utiliza bucles anidados y concatenación de cadenas.

## 🧠 Conceptos que aparecen

- Bucles anidados
- Concatenación de cadenas
- Control de entrada

## 🧪 Casos que debo probar

- [ ] Probar valores pequeños
- [ ] Probar 0 y 50
- [ ] Comprobar el formato de cada fila
